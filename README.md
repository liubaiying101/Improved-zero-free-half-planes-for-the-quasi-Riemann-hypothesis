# Improved-zero-free-half-planes-for-the-quasi-Riemann-hypothesis
Recently, a uniform 7/8 zero-free half-plane for finite-order Hecke L-functions over Q(\sqrt{-3}) and its transfer to Dirichlet L-functions was given by OpenAI. By varying all possible parameters, we slightly improve the bound to be 0.874957019420098946.

We open this new repository which has fewer and cleaner lean related files.
